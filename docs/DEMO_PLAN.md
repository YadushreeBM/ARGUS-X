# Hackathon demo story

1. Show a CCTV clip with several people; explain that each person gets a stable ID.
2. Show a person disappearing behind an obstruction or leaving view.
3. Show the identity retained in the lost-track bank.
4. Show the person reappearing; explain the appearance/motion/time score and ambiguity margin.
5. Show the recovery event and annotated output retaining the old ID, if the clip supports a reliable match.
6. For multi-camera mode, show two approximately synchronized camera recordings and the global-ID event table.
7. Show CSV/JSON logs and compare results with a ByteTrack-only baseline.

Never stage or claim a successful recovery if the system actually created a new ID or matched the wrong person. Explain confidence and limitations honestly.
